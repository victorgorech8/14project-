Методология построения портфеля акций

Проект: оптимизация и диверсификация портфеля ценных бумаг на данных Московской биржи.

Цель документа: объяснить, что происходит внутри сервиса, какие данные используются, как рассчитываются риски и доходности, и как итоговый алгоритм выбирает акции и веса портфеля.

Документ описывает исследовательскую и учебную методологию. Расчеты не являются индивидуальной инвестиционной рекомендацией.

1. Общая идея

Классический подход к портфелю часто строится вокруг модели Марковица: максимизация ожидаемой доходности при заданном риске или минимизация риска при заданной доходности. На практике у этого подхода есть проблема: ковариационная матрица финансовых рядов нестабильна, особенно когда активов много, а наблюдений мало. Поэтому в проект добавлен более робастный ансамблевый подход.

Новый модуль AdvancedPortfolioPipeline объединяет несколько современных направлений: Hierarchical Risk Parity, Black-Litterman, CVaR-оптимизацию, графовую модель рынка и ансамблирование. Такой подход уменьшает зависимость результата от одной модели и лучше учитывает структуру риска.

2. Входные данные

API принимает трехмерный тензор:

tensor_3d[день, тикер, признак]

Также передается список тикеров tickers, порядок которого должен совпадать со вторым измерением тензора.

Первая feature в тензоре используется как ценовой ряд. Обычно это цена закрытия CLOSE. Остальные признаки могут описывать объемы, максимум, минимум, количество сделок и другие рыночные характеристики.

3. Предобработка

  1. Проверка формы данных: тензор должен быть трехмерным, а количество тикеров должно совпадать с размерностью тензора.
  2. Извлечение цен: из tensor_3d[:, :, 0] берется матрица цен размера days x tickers.
  3. Обработка пропусков: некорректные значения заменяются медианой соответствующего инструмента.
  4. Расчет доходностей: для каждого тикера считается дневная доходность.
r(t, i) = price(t, i) / price(t - 1, i) - 1

Для снижения влияния экстремальных выбросов доходности ограничиваются 1-м и 99-м процентилями. Это важно для финансовых рядов, где отдельные аномальные свечи могут исказить весь портфель.

4. Оценка ожидаемой доходности

Ожидаемая доходность оценивается не обычным средним, а экспоненциально взвешенным средним EWMA. Последние наблюдения получают больший вес, потому что свежие рыночные режимы обычно важнее старых.

E[r_i] = sum(w_t * r(t, i)), где w_t пропорционален decay_factor^(T - t)

В текущей реализации используется decay_factor = 0.97.

5. Оценка риска

Для риска строится ковариационная матрица доходностей. Чтобы она была устойчивее, применяется shrinkage-подход: выборочная ковариация смешивается с диагональной целевой матрицей.

Cov_shrink = (1 - alpha) * Cov_sample + alpha * Cov_target

Это снижает переобучение на исторических данных и делает оптимизацию стабильнее, особенно для небольших выборок.

6. Кластеризация активов

Акции группируются по признакам риска, доходности, downside-risk, momentum и корреляционной структуре. Для этого используется KMeans, если доступен scikit-learn. Если библиотека недоступна, предусмотрен простой fallback.

Кластеры нужны не только для визуализации. Они помогают выбирать акции так, чтобы портфель был диверсифицирован по группам похожих инструментов.

7. Методы построения портфеля

7.1. Hierarchical Risk Parity, HRP

HRP строит иерархическое дерево активов на основе корреляций. Затем активы упорядочиваются по дереву, а капитал рекурсивно распределяется между группами так, чтобы больше веса получали менее рискованные кластеры.

Преимущество: HRP не требует прямой инверсии ковариационной матрицы, поэтому часто стабильнее классического Марковица.

7.2. Black-Litterman с ML-style views

Black-Litterman объединяет нейтральное рыночное ожидание и views модели. В проекте views формируются автоматически: ожидаемая доходность берется из EWMA, а уверенность зависит от волатильности. Чем выше волатильность инструмента, тем ниже уверенность в прогнозе.

Преимущество: модель не делает слишком агрессивных ставок только из-за краткосрочного роста цены.

7.3. CVaR-оптимизация

CVaR показывает средний убыток в худших 5% сценариев. Это более практичная мера риска, чем обычная волатильность, потому что инвестора особенно интересуют тяжелые хвосты распределения.

CVaR_95 = средний убыток среди худших 5% дневных исходов

Веса ищутся через cross-entropy policy search: алгоритм генерирует много случайных портфелей, оценивает их по целевой функции, оставляет лучшие и постепенно сдвигает распределение весов в сторону более качественных решений.

7.4. Graph Attention / графовая модель рынка

Акции рассматриваются как граф: вершины — тикеры, ребра — сильные корреляционные связи. Затем оценивается центральность акций в графе. Если акция слишком центральна, она может быть источником системного риска: падение такой акции часто связано с движением всего рынка или сектора.

Attention-оценка повышает вес активов с хорошим отношением доходности к риску и momentum, но штрафует чрезмерно центральные активы.

7.5. Ensemble

Метод ensemble используется по умолчанию. Он смешивает веса четырех моделей:

  • 35% HRP;
  • 25% Black-Litterman;
  • 25% CVaR;
  • 15% Graph Attention.

Ансамбль нужен, чтобы не зависеть от одного предположения о рынке. Если один метод ошибается из-за смены рыночного режима, другие методы частично компенсируют эту ошибку.

8. Как находится итоговый портфель

  1. Сервис получает тензор данных и список тикеров.
  2. Из цен рассчитываются дневные доходности.
  3. Оцениваются ожидаемые доходности через EWMA.
  4. Строится shrinkage-ковариация и корреляционная матрица.
  5. Акции группируются в кластеры похожих инструментов.
  6. Выбранный метод считает веса для всех акций.
  7. Веса ограничиваются параметром max_weight, чтобы одна акция не заняла слишком большую долю.
  8. Выбираются топ-активы по весу. Количество можно задать через target_assets.
  9. Веса выбранных активов нормализуются так, чтобы сумма была равна 1.

11. Научная новизна

Новизна проекта заключается в гибридной архитектуре составления портфеля. Вместо одного классического оптимизатора используется ансамбль методов, которые смотрят на рынок с разных сторон:

  • робастная shrinkage-оценка ковариации вместо нестабильной выборочной матрицы;
  • иерархическая диверсификация HRP;
  • учет хвостового риска через CVaR;
  • автоматические views в духе ML для Black-Litterman;
  • графовая attention-поправка, вдохновленная современными GNN-подходами;
  • ансамблирование весов для снижения модельного риска.

12. Ограничения и дальнейшее развитие

Текущая версия оценивает портфель только по историческим рыночным данным. Для промышленного применения можно добавить комиссии, ликвидность, ограничения на оборот портфеля, стресс-тестирование, walk-forward backtesting и полноценную нейросетевую модель прогнозирования доходностей.

Следующий сильный шаг — добавить backtesting-модуль: регулярно пересобирать портфель на историческом окне и сравнивать результат с индексом МосБиржи, равновесным портфелем и классическим Markowitz baseline.
